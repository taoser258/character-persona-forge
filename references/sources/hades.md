### 8.2 官方可直接取得

- 官方简介与类型定位：Supergiant 的 rogue-like dungeon crawler；玩家扮演冥界王子 Zagreus，试图逃出冥界。
- 官方语言列表确认简体中文为正式支持语言；因此中文译文可用 `official_zh`，不是社区汉化。
- 官方公告、版本更新与平台信息；用于 `version_snapshot`，不用于角色性格论证。
- 官方中文对话文本：由游戏内本地化提供，但本次通过社区字幕转储读取，引用时标“社区转储（官方简中）”。

### 8.3 官方缺口（须社区补或明确标缺）

- 官方站与商店页没有 Megaera（墨纪拉）等角色的逐条档案；角色性格、关系和剧情主要来自游戏内对话与社区整理。
- 没有官方在线全文剧本/语音库；本次使用 GitHub 社区字幕转储，属于 S3。
- 官方中文文本可读，但转储可能随版本/补丁变化；关键句需与第二来源或游戏内文本交叉。
- 战斗语音、冥府日常对话、恋爱线对话是不同场景；不能把战斗嘲讽当日常语气。
- 恋爱线是可选内容；不能默认 Zagreus 与 Megaera 已复合或已进入恋爱关系。
- 《Hades II》是续作，主角为 Melinoë；不把续作关系、剧情和角色状态并入本作。

### 8.6 抽取顺序与边界

官方商店页/语言列表 → 官方公告确认版本 → GitHub 英中字幕对照取短句 → 萌百/Bilibili 交叉关系与性格 → Fandom 仅在可达时补缺。

- 先区分场景：`MegaeraHome` 是冥府日常，`MegaeraField` 是塔耳塔罗斯战斗；同一角色在两处的语气不同。
- 台词按 ID 取英中对照；英文原文进原文列，官方简中进译文列，不把译文写成英文原文。
- 恋爱线是可选分支；核心人格不依赖玩家是否走恋爱线，只写“旧情、职责、未解的心结”。
- 关系结论至少两个来源；只有字幕时标 `community-only` / `partial`。
- 剧透闸门：Persephone、真结局、关系修复与续作状态默认按用户进度处理。

### 8.7 已知取证陷阱

- **官方有中文，但转储不是官方**：Steam 语言列表证明官方简中存在；GitHub 字幕是社区转储，标 S3，不称“官方网页原文”。
- **转储许可不明**：仓库未声明许可证；只引用短句，不复制整份 CSV 或大段对话。
- **Fandom 不可达**：本环境直连超时；记录不可达，不硬刷，改用字幕转储与中文资料。
- **战斗语音 vs 日常对话**：`MegaeraField` 多为嘲讽、命令、战吼；`MegaeraHome` 才是关系与日常语气。混用会把角色写成只会打架的暴脾气。
- **恋爱线可选**：不能默认玩家已选择 Megaera 线，也不能把“你是我的”当成日常占有宣言；它是战斗中的旧情与占有欲，需要按关系进度使用。
- **希腊神话原型 vs 游戏正典**：Megaera 在神话中是复仇女神之一，但游戏的血缘、职位、与 Nyx/Zagreus 的关系有自己的设定；不要把神话版本直接当游戏事实。
- **续作隔离**：《Hades II》是另一部作品，角色状态与关系可能变化；不并入本作。
- **版本差异**：转储可能来自特定补丁；台词/关系文本若有更新，以当前正式版为准并记录快照。
- **剧透**：Persephone、真结局、关系修复属于重剧透；默认先询问。
