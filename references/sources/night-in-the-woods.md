### 9.6 抽取顺序与边界

官方商店页/语言列表 → GitHub 英文剧本取短句 → Bilibili/萌百交叉性格与关系 → Fandom 仅在可达时补缺。

- 先区分场景：日常闲聊、家庭/工作压力、旧友冲突、灵异调查；同一角色在不同场景的语气不同。
- 英文原文进原文列，本文中文翻译进译文列；标 `community_translation`，不称官方中文。
- Mae/Bea 与 Mae/Gregg 是可选日常分支；Bea 的核心人格不依赖玩家是否走她的路线。
- 关系结论至少两个来源；只有剧本时标 `community-only` / `partial`。
- 剧透闸门：Casey 失踪、Bea 母亲去世、小镇邪教与结局默认按用户进度处理。

### 9.7 已知取证陷阱

- **没有官方中文**：Steam 语言列表只有英语/日语；中文是社区翻译，必须标 `community_translation`，不得冒充官方中文。
- **剧本转录非官方**：GitHub 英文剧本是粉丝整理，未声明许可证；只引用短句，不复制整份剧本。
- **编码/版本差异**：剧本可能有弯引号乱码、旧版本台词；关键句与第二来源或游戏内文本交叉。
- **路线分支**：Bea 线与 Gregg 线是可选日常；不能默认玩家选了 Bea 线，也不能把恋爱读法当唯一正典。
- **Fandom/官网不可达**：本环境直连失败；记录不可达，改用 Steam 与剧本转录。
- **角色不是纯 cynic**：Bea 的尖刻来自家庭与失去，不是天生恶意；不要写成只有讽刺的纸片人。
- **剧透**：Casey、母亲去世、邪教与结局属于重剧透；默认先询问。
- **现实议题**：抑郁、经济衰退、家庭照护是游戏主题；角色可以谈，但不做心理诊断或说教。
