# 通用来源规则

> 四款游戏共用：检索顺序、SPA/登录墙处理、跨游戏质量规则、维护记录。
> 各游戏专属入口见同目录 `genshin.md` / `hsr.md` / `zzz.md` / `wuwa.md`。

## 0. 通用顺序与规则

### 0.1 检索顺序
1. 官方角色页/角色档案：称号、简介、CV、阵营、公开身份。
2. 官方 PV/角色演示/版本 PV/动画短片：气质、台词、演出信息。
3. 官方公告/版本页/活动页/官方社媒：版本节点、活动剧情、生日/节日文案。
4. 官方漫画/读物/访谈/设定集：补充世界观与角色前史。
5. 官方平台 Wiki（HoYoWiki、观测枢、开拓者笔记、库街区 WIKI）：S2，交叉核对，不单独支撑关键事实。
6. 社区 Wiki（BWIKI、Fandom、萌娘百科、Honey Hunter）：S3，只补官方缺口并标注“社区转录”。

### 0.2 通用规则
- 四款游戏的官网、角色页、米游社/库街区多为 SPA；直接请求网页往往只得到空壳。用无头浏览器等 `networkidle` 后取 DOM，或先搜索索引再进单页。
- 视频优先官方字幕/简介；无字幕时只引用可核实原句；无法逐字确认就转述，标“非逐字/自动字幕”。
- 登录墙、地区 403、Cloudflare 拦截：记录“不可达”，换同级别来源；不得假装读过。
- 社区 Wiki 的语音/剧情页是玩家转录，不是官方文字稿；正文标“社区转录”，并尽量用第二个来源交叉核对。
- 抓取后立即记录 URL、标题、版本、语言、访问日期；防改版下架。
- 角色有本名/称号/形态/同名角色时，先建别名表（如“三月七·巡猎”“姬子•启行”），再跨源合并。

## 1. 跨游戏质量规则

1. **官方原文优先**：角色页/公告/PV 能直接读到的，不用社区总结替代；读不到就写“不可达”。
2. **社区转录必须标注**：BWIKI/Fandom/萌娘的语音与任务页是玩家转录，正文标“社区转录”，置信度不写“官方原文”。
3. **视频台词**：有官方字幕才可标“逐字”；自动字幕/ASR 标“非逐字”，不要加引号冒充原句。
4. **多语对照**：官方中文优先；英文/日文只用于理解语气差异，不直接搬翻译腔。
5. **版本与剧透**：记录 `version_snapshot`；最新正式上线为默认；早期阶段入附录并标剧透等级；不用泄露/测试服内容。
6. **别名与形态**：先建本名/称号/形态表；同一角色的不同形态不得混用记忆与称呼。
7. **停止条件**：每个核心章节有合格证据、关键结论已交叉核对、连续三次检索无新增重大事实，或达到来源/证据预算。
8. **缺口处理**：预算用尽仍有空白，写“资料不足/未核实”；不要用模型记忆补齐。
